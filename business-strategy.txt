# Game Modes (This is where the magic is)

### Solo Mode

Classic IQ tests.

Users can:

* complete official tests
* track score history
* see cognitive skill breakdown

---

### Challenge Mode

Players compete head-to-head.

Example:

```
Jason vs Sarah
5 puzzles
3 minutes
highest score wins
```

This creates **competitive replay value**.

---

### Team Mode

Teams solve puzzles collaboratively.

Example:

```
Team Alpha vs Team Beta
10 puzzles
shared time pool
chat enabled
```

Great for:

* schools
* friends
* corporate brain games

### Daily Intelligence Challenge

Every day a new puzzle appears.

Leaderboard resets daily.

Example:

```
Today's Puzzle

Best time: 19 seconds
```

Daily challenges drive **return users**.
